# Clawd для ПК 🦀

Пиксельный питомец, который живёт на рабочем столе Windows: гуляет по панели задач, катается на окнах, реагирует на то, что ты делаешь, и умеет выполнять просьбы через ИИ.

> Неофициальный фан-проект, не связан с Anthropic.

## Что умеет

- **Живёт поверх всех окон.** Физика на 60 fps: можно таскать, бросать и гладить. Катается на окнах, глазами следит за курсором.
- **Реагирует на экран.** Комментирует то, что открыто. Когда запущена игра, уходит в портал и иногда выглядывает поболеть. Может смотреть видео вместе с тобой.
- **Ассистент** (`Ctrl+Alt+K` или двойной клик): «закрой фаерфокс», «громче», «найди в телеге…». Простые команды работают без ИИ, остальные идут через Claude, Gemini или OpenAI. Всё опасное (закрыть всё, выключить комп) делается только после подтверждения, системные процессы он не трогает.
- **Объяснить область экрана** (`Ctrl+Alt+S`): выделяешь кусок экрана, он объясняет, переводит или решает.
- **Голос** (держи `Ctrl+Alt+V` и говори) и озвучка ответов через SAPI.
- **Буфер обмена:** перевести или пересказать скопированное. Помогает с ошибками.
- **Гардероб:** 107 вещей в семи слотах (голова, лицо, шея, в лапе, спина, узор, аура) и 34 окраса. Надевается всё сразу, по вещи на слот: цилиндр, очки, бабочка, меч, плащ, полоски и огненная аура одновременно. Часть открыта сразу, остальное — за ачивки. Отдельная вкладка в настройках, у каждой вещи живое превью, есть «Случайный образ». Аура — переливающееся пиксельное свечение по контуру Клодика и всего надетого плюс частицы; во вкладке «Аура» можно оставить только свечение или только частицы.
- **Жизнь:** погода по городу (Open-Meteo), ночной колпак с 22 до 7, утренняя сводка и вечерний итог дня, ачивки, праздничный декор, иногда какашки (кликни, чтобы убрать).
- **Звонки и музыка:** во время звонка ведёт себя тихо, под музыку танцует.
- **Связь с телефоном** (необязательно): работает в паре с Android-версией Clawd и [PhotoSync](#photosync) по локальной сети.

## Установка

Нужен Windows 10/11 и [Python 3.10+](https://www.python.org/downloads/) (галочка «Add to PATH» при установке).

```bat
git clone https://github.com/f3403487-arch/clawd-pc.git
cd clawd-pc
pip install --user -r requirements.txt
clawd_pc.bat
```

Зависимости из `requirements.txt` необязательные: без `pillow` не будет работать `Ctrl+Alt+S` и всё, что смотрит на экран, без `pycaw` не будет реакции на звук в звонках. Всё остальное работает на чистом Python.

Автозапуск: создай ярлык на `clawd_pc.bat` в папке `shell:startup`.

## Настройки

`clawd_settings.bat` или правый клик по Клодику → «Настройки». Там город, имя, ключ ИИ и поведение. Гардероб и окрас — на своей вкладке (или правый клик → «Гардероб…»).

Вся одежда описана в `clawd_wardrobe.py` строками-картинками: буква — цвет, точка — пусто. Тот же файл — источник гардероба для [Clawd на телефоне](https://github.com/f3403487-arch/clawd-phone): там он превращается в Kotlin генератором `tools/gen_wardrobe.py`.

Ключ (Claude `sk-ant-…`, Gemini `AIza…` или OpenAI `sk-…`) хранится только локально в `clawd_pc.json`. Этот файл в `.gitignore`, не коммить его.

## Порты

| Порт | Зачем |
|---|---|
| `127.0.0.1:8767` | события от PhotoSync (`/event`) и окно настроек |
| `0.0.0.0:8769` | связь с телефоном по LAN (`/phone`, нужен код синхронизации) |

## PhotoSync

Если рядом лежат `photo_sender.py` и `photo_receiver.py` из PhotoSync, Клодик прибегает с файлом, когда он приходит с телефона, и убегает с ним, когда отправляешь. Файл, брошенный на Клодика, улетает на телефон. Без PhotoSync всё остальное работает как обычно.
